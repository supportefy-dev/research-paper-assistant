# API notes (for maintaining scholar.py)

Verified live on 2026-10-20. Read this before changing the scripts or calling the APIs by hand.

| API | Auth / limits | Gotchas |
|---|---|---|
| OpenAlex `api.openalex.org` | No key needed, but keyless calls share **1,000 credits/day per IP** (a whole office or campus). Search = 10 credits, filter list = 1, single lookup (`/works/doi:`, `/sources/issn:`) = 0. Free key: $1/day = 10,000 credits (openalex.org/settings/api). `mailto` no longer raises limits | `search=` matches full text: sorted by citations it returns off-topic blockbusters, so use `title_and_abstract.search`. `per_page` max 200. Cursor paging past page 1 needs a key. Abstracts come as `abstract_inverted_index`, null for many publishers (Elsevier). DOIs come as full URLs. A 404 is an HTML page. No quartile/SJR field |
| Crossref `api.crossref.org` | No key. Single record: 5/s public, 10/s polite (mailto). Lists/search: **1/s public, 3/s polite** | 429 has an empty body and no Retry-After. A 404 body is text, not JSON. A 404 is not proof of fabrication: DataCite DOIs (datasets, arXiv, Zenodo) live elsewhere, so check `doi.org/api/handles/<doi>` (responseCode 1 = registered). `select=` silently drops `updated-by`: never use it for retraction checks. `query.bibliographic` always returns hits, even for invented citations: compare title, first author and year |
| Retractions | In Crossref `updated-by` (includes Retraction Watch data) | Types are messy: lowercase, `-` to `_`, treat retraction, partial_retraction, withdrawal, removal, expression_of_concern as integrity flags. Dedupe publisher + retraction-watch duplicates. A DOI with `update-to` IS a notice. OpenAlex `is_retracted` is a second opinion |
| doi.org content negotiation | Via Crossref limits | `text/x-bibliography` has no charset: decode bytes as UTF-8. Output uses en dashes in page ranges (normalise). Crossref stores initials as 'AJ', so negotiated APA drops initials: scholar.py builds APA itself |
| Semantic Scholar `api.semanticscholar.org` | Keyless shared pool, 429s even on the first call, no headers. Free key (form on their API page, header `x-api-key`) starts at 1 rps | `limit` max 100 (101 returns 500, which retry loops spin on). `/paper/search/match` always returns something: never use it alone. Good fallback for abstracts |
| DOAJ `doaj.org/api` | No key, 2 req/s, excess is queued not rejected | ISSN must be hyphenated. Absent from DOAJ is normal for subscription journals |
| Open Library `openlibrary.org/search.json` | No key | `isbn=` or `title=` + `author=`; returns all editions' publishers and years: cite the edition used |
| Europe PMC `ebi.ac.uk/europepmc/webservices/rest/search` | No key | `query=DOI:"<doi>"&resultType=core&format=json` gives `abstractText` for biomedical / life-science papers: last abstract fallback |
| OpenAlex free key | `POST https://api.openalex.org/api-keys {"email": ...}` returns 201 with `api_key` + `status: pending_activation` and emails an activation link (valid 7 days) | Only with the user's explicit OK and their own email. Save the key straight to `~/.config/research-paper-assistant/openalex.key` without printing it: a second POST within a day returns 409 `activation_pending` and no key. After the click the key is also shown at https://openalex.org/settings/api-key. Until activated, calls with the key get 401 |
| Crossref locator check | `query.bibliographic="<journal> <volume> <page>"` | Finds the paper that really sits at a cited journal/volume/page: how `verify` exposes fabricated references that borrow a real locator |
| SJR | No API. Cloudflare + robots.txt block scripts | User downloads the CSV. `;` delimiter, comma decimals, UTF-8, header 'Publisher' appears twice, ISSNs without hyphens comma-separated, per-category quartiles inside `Categories` as `Name (Q1); ...`, '-' = not ranked. Column names change by edition: match by name |

Windows: the console is cp1252, so every script calls `sys.stdout.reconfigure(encoding="utf-8")`; run with `python -X utf8` (note `python -I` ignores PYTHONIOENCODING). In PowerShell 5.1 `curl` is Invoke-WebRequest: use `curl.exe` or the Bash tool.
